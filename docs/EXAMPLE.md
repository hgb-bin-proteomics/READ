# Example Data and Usage

Please download the example data from here: [http://u.pc.cd/oIWrtalK](http://u.pc.cd/oIWrtalK).

Then extract the `example.zip` file and you should get the following contents:
- `20250920_Neo6A1_TH073_TT_THIDmulti005_DIA_mz1_ij8_53c75ng_1.raw`
  - RAW file, DIA, 1 m/z isolation window
- `config.toml`
- `resolution.csv`
- `Chimerys/`
  - Chimerys results folder
- `DIA-NN/`
  - DIA-NN results folder
- `Spectronaut/`
  - Spectronaut results folder

> [!IMPORTANT]
>
> This example assumes you are running the example on a Windows PC. If you are not
> running Windows you need to convert the RAW file to .mzml and can only use the CLI!
